# Pixel Forge

## Register

product

## Users

Desktop game creators learning through immediate editing and playtesting.

## Product Purpose

A local retro game studio. The required deliverable is the prompt's complete first playable slice: edit terrain, place entities, configure collision, save, reopen, play and export.

## Brand Personality

Tactile, inventive, colorful. A fictional 1990s development workstation, based on the supplied references with original assets.

## Anti-references

No copied game characters or assets, decorative mock controls, fictional history, smooth rendering or minimalist dashboard styling.

## Design Principles

Canvas first. Every visible tool must work. Preserve editable data during play. Empty projects belong to users; samples are labeled. Local files are portable.

## Accessibility & Inclusion

Labeled controls, keyboard shortcuts, visible focus, scalable browser UI, reduced motion, and text as well as color for states.
